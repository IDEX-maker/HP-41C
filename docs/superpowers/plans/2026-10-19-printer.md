# HP 82143A Printer Emulation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The emulated HP-41 prints through a modelled HP 82143A: output on an on-screen paper strip, with a user-selectable destination (screen only, browser print dialog, save as PDF) and mode (collect then print, or print immediately).

**Architecture:** `PRINTER.ROM` is loaded as a plug-in page (page 6). A new `printer.js` models the printer chip on the peripheral bus (hooked into `nut.js` `_pfRead` / `_pfWriteN` / `ST_SELPF` flag test); its protocol is derived by probing the real ROM, then implemented test-first. A `Tape` collects lines; `app.js` renders it and prints it with `window.print()` and a print-only stylesheet.

**Tech Stack:** Plain browser JavaScript (no build), Node scripts in `tools/` for tests, service worker (`sw.js`).

**Spec:** `docs/superpowers/specs/2026-10-19-printer-design.md`

## Global Constraints

- No server, no native helper, no new dependencies; works offline and as a PWA/Android app.
- Printing only via the browser print dialog (`window.print()`); no silent printing.
- Default destination: on-screen paper only; default mode: collect, with **Print tape** and **Clear tape** buttons. Settings persist in localStorage (`hp41.printdest`, `hp41.printmode`) via the existing `lsGet`/`lsSet`.
- Tape width 24 columns, 5x7 dot font.
- Works with every memory config (`c`, `cv`, `cx`).
- ROM file bundled as `roms/PRINTER.ROM` (8192 bytes), same copyright note as the other ROMs.
- Tests are Node scripts in `tools/` using `tools/lib.js`; run with `node tools/<name>.js`, exit code 0 = pass.

## Review Focus

- Printer ROM not loaded (or removed): calculator behaves exactly as before, printer flag stays false, nothing hangs.
- A program looping `PRX` 50 times finishes (printer never stays busy forever).
- Power cycle, memory-config change or `MEMORY LOST` reset: printer state resets, no stuck busy flag.
- Very long tape: capped at 5000 lines (oldest dropped), page stays responsive.
- **Print tape** with an empty tape does nothing (button disabled, no dialog).
- Non-ASCII/special characters (e.g. Σ, ≠, ↑) print as a stand-in glyph, never crash the renderer.
